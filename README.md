# UrbanPulse — GitHub Pages (Local SQLite)

## التشغيل على GitHub Pages
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. افتح **Settings → Pages**.
3. من **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
5. افتح الرابط الذي يعطيك GitHub Pages.

## قاعدة البيانات
- لا يوجد Flask أو Python أو PHP أو Node.js.
- يستخدم المشروع محرك SQLite داخل المتصفح عبر `sql.js` (WebAssembly).
- يتم حفظ ملف قاعدة البيانات محلياً داخل IndexedDB على نفس المتصفح والجهاز.
- عند أول تشغيل تُحمّل قاعدة `urbanpulse.db` المرفقة، ثم تُحفظ تعديلات المستخدم محلياً.
- كل جهاز/متصفح لديه نسخة مستقلة؛ البيانات لا تنتقل تلقائياً بين الأجهزة ولا تكون مشتركة.
- زر إعادة الضبط يعيد قاعدة البيانات المحلية إلى النسخة الأصلية المرفقة.
- يلزم اتصال بالإنترنت عند أول تحميل للموقع لتحميل مكتبة sql.js وملف WebAssembly من CDN.

## ملاحظات مهمة
GitHub Pages يستضيف ملفات ثابتة فقط، لذلك SQLite هنا تعمل داخل المتصفح، وليست قاعدة بيانات مركزية على GitHub. امسح بيانات الموقع أو IndexedDB من إعدادات المتصفح فقط إذا كنت تريد حذف بيانات ذلك الجهاز.
